# Today Tomorrow Weather
今日、明日の天気予報。

## 都市の検索と保存

初期登録の都市はありません。初回は都市を検索するか、現在地を取得して始めます。保存済みの都市は引き続き復元します。

- 「日本の都市を検索」に日本語の地名を2文字以上入力して検索し、候補を選択します（例：横浜、札幌市、大田区）。日本国内の候補を都道府県名付きで表示します。見つからない場合は市区町村名で検索してください。
- 検索で選んだ都市を地域一覧に追加し、最後に選んだ都市と追加した都市をlocalStorageに保存します。同じブラウザ・同じサイトで開くと復元します。GPS座標は保存しません。
- ストレージの利用が制限されている場合は保存できない旨を表示します。ブラウザのデータ削除により保存内容は消えます。
- 検索にはOpen-Meteo Geocoding API（`geocoding-api.open-meteo.com`）を使用します。入力した検索語は検索時にAPIへ送信します。APIキーは不要です。地名データにより候補が見つからない場合があります。

開発用の起動：`python3 -m http.server 8000 --bind 127.0.0.1`

## 通信とテスト

天気取得・都市検索は、通信エラー、タイムアウト、一時的なサーバーエラー（HTTP 502/503/504）の場合に1回だけ自動再試行します。各試行のタイムアウトは12秒です。継続して失敗する場合は日本語の案内を表示します。

通信処理の回帰テスト：`node --test tests/weather-api.test.cjs`
